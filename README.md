# NOXIS — Phase 2

Самостоятельный Windows x64 синтезатор для atmospheric/wave/dark phonk.
C++20, JUCE 8.0.16-security, CMake. DSP не зависит от JUCE.

## Сборка

Нужны Visual Studio 2022 с Desktop development with C++, Windows SDK, CMake 3.22+ и Git.

```powershell
.\scripts\build.ps1
.\build\NOXIS_artefacts\Release\NOXIS.exe
```

`./scripts/build.ps1 -Run` собирает, проверяет и открывает приложение.
`./scripts/build.ps1 -DspOnly` собирает движок и тесты без JUCE.

В Developer PowerShell for VS 2022 можно выполнить вручную:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure
```

JUCE закреплён на commit `ea77444750de45e036e0279bb0291144bf8e3688`.
Первая сборка скачивает зависимость; для сборки офлайн поместите эту версию в
`external/JUCE`. Готовая программа работает без интернета. Лицензия зависимости —
`external/JUCE/LICENSE.md`.

## Клавиатура

По обозначению FL Studio **Q = C5 = MIDI 60 = 261,626 Гц**, Z = C4 = MIDI 48.
Верхние белые клавиши: Q W E R T Y U I; чёрные: 2 3 5 6 7.
Нижние белые: Z X C V B N M; чёрные: S D G H J.

Используются физические scan codes Windows: музыкальная раскладка сохраняется при
переходе между английским и русским языком. Кнопка KEYS включает музыкальный ввод.
`[` / `]` или нижние −/+ меняют октаву; список C…B меняет root note.
При вводе текста, Ctrl/Alt и потере фокуса музыкальные клавиши освобождаются.
Escape / PANIC заглушает голоса и хвосты эффектов. Можно играть мышью и внешним MIDI.
Pitch bend работает отдельно по MIDI-каналам, диапазон задаётся Bend range.

## Звук и режимы

- Два осциллятора: sine, PolyBLEP saw/square, ограниченная гармониками triangle.
- Восемь полифонических голосов, внутри каждого unison 1–8 с нормализацией,
  detune, spread, width и управляемой рандомизацией фазы.
- Независимые ADSR и stereo low-pass; sub/noise, дополнительная настройка OSC B.
- Mono, legato, glide, sustain CC64, корректное освобождение и stealing голосов.
- Два LFO: sine, triangle, saw, square, sample-and-hold; phase/retrigger/depth.
- В MODULATION задаются назначения pitch, cutoff, level и width, плюс envelope → cutoff.
  Назначение действует при наличии соответствующей связи в Routing.
- При Sync=OFF Rate измеряется в Гц. При Sync=ON — cycles/beat (cpb),
  с округлением к 1/16, 1/8, 1/4, 1/2, 1, 2, 4, 8 или 16; BPM задаётся в standalone.
- Настоящие saturation, chorus, ping-pong/stereo delay и FDN reverb: bypass и mix.
  Reverb Size меняет затухание; Width относится к unison, эффекты имеют собственное стерео.

PRO даёт точные параметры; значения под регуляторами можно редактировать, двойной
щелчок возвращает исходное значение. NOOB использует то же состояние: Tone — cutoff,
Movement — detune и движение LFO1, Width — stereo-unison, Drive — сатурация,
Space — reverb/delay. Макросы могут включать соответствующие блоки.

Осциллограф показывает фактический выход. Два индикатора измеряют левый и правый
канал. ADSR-кривая и базовая характеристика фильтра следуют параметрам; линии LFO
показывают фактическую активность. GUI обновляется при 30 Гц.

## Routing

Схема управляет реальной обработкой. Перестановка Saturation и Filter меняет звук.
Осцилляторы и Mixer имеют аудиопорты, LFO/Envelope — модуляционные; типы проверяются.
Аудиоциклы запрещены, Output обязателен.

- Перетаскивайте ноды за тело; выбранный нод открывает параметры справа.
- Тяните выходной порт на совместимый вход для соединения.
- Тяните занятый вход для переподключения.
- Выберите линию и нажмите Delete либо щёлкните по ней правой кнопкой.
- Auto Layout, Reset, Fit, Zoom, Pan и Undo/Redo доступны в редакторе.
- Незавершённый граф явно обозначается как черновик. Пока он невалиден,
  продолжает звучать последняя валидная схема; сохранение пресета блокируется.

Граф валидируется и компилируется в GUI. Аудиопоток получает фиксированный план
через атомарный снимок на границе блока и плавно меняет конфигурацию.

## Пресеты

36 оригинальных тембров: четыре исходных плюс 32 новых — BASS, LEAD, PAD,
PLUCK, PHONK, FX. Есть категории, поиск по имени/описанию/тегам, избранное,
описания, рекомендуемый диапазон MIDI, загрузка и предварительное прослушивание.
Происхождение и источники — `presets/SOURCES.md`.

Пользовательские пресеты по умолчанию сохраняются в Documents/NOXIS Presets;
этот каталог сканируется при запуске. Избранное хранится в пользовательском
Application Data/NOXIS/favorites.txt. Звёздочка в названии означает изменения.

`.noxis` v2 сохраняет все параметры, метаданные, положения нодов и связи.
Phase 1 v1 загружается с начальными значениями новых параметров. Загрузка невалидного
пресета не меняет состояние. Четыре исходных файла v1 сохранены в `presets/`,
полная экспортированная библиотека v2 — в `presets/Factory/`.

## WAV и проверки

```powershell
New-Item -ItemType Directory -Force renders
.\build\Release\noxis_render.exe renders\phase2-demo.wav presets\Factory
```

Рендерер создаёт 24-секундную PCM16 stereo демонстрацию восьми тембров при 48 кГц.
Второй аргумент экспортирует все заводские пресеты. Отдельный library-тест
рендерит каждый из 36 тембров, проверяет уровни, конечность, различия и round-trip.

```powershell
Start-Process -FilePath .\build\NOXIS_artefacts\Release\NOXIS.exe -ArgumentList '--smoke-test' -WorkingDirectory $PWD -Wait
```

Закройте обычный экземпляр перед проверкой. Тест открывает GUI, играет короткий
аккорд через аудиоустройство, записывает stereo `standalone-smoke.wav` и отчёт
`standalone-smoke.txt`, затем закрывается. Проверка данных callback не заменяет
прослушивание акустического выхода.

Текущее состояние и ограничения — `PROJECT_STATE.md`, следующие задачи — `ROADMAP.md`.
